# Roadmap

This file is intentionally not a list of implemented capabilities. Use [Supported and unsupported behavior](SUPPORTED.md) for the current evidence-backed frontend boundary.

Potential future work includes richer report settings and column personalization, interactive grouping and advanced filtering, more chart options, dashboard authoring, drill-down, scheduling, role-aware UI, auditing, favorites, and a report designer. None of those items is a delivery commitment or supported behavior until its runtime, validation, tests, and documentation land together.

The legacy SQL parser has its own historical tests but is not part of active report/dashboard execution; see [Query engine status](QUERY-ENGINE.md).
